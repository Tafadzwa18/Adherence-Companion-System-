# Key Features

## Role-Based Access Control (RBAC):** Customized user model supporting three distinct roles:
  1. Patients: Manage personal prescriptions, log intake status, and review adherence history.
  2. Clinicians: Monitor assigned patient rosters, inspect compliance percentages, and spot non-adherent trends.
  3. Caregivers: Assist assigned patients by viewing schedules and tracking daily logs.

## Dual Interface Options:
     
  1. Web UI: Server-side rendered Django templates styled with responsive Tailwind CSS.
  2. REST API: Fully decoupled endpoints powered by DRF with JWT Authentication.
