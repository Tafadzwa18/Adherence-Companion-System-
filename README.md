# Key Features

## Role-Based Access Control (RBAC):** Customized user model supporting three distinct roles:
  ### Patients: Manage personal prescriptions, log intake status, and review adherence history.
   ### Clinicians: Monitor assigned patient rosters, inspect compliance percentages, and spot non-adherent trends.
   ### Caregivers: Assist assigned patients by viewing schedules and tracking daily logs.

## Dual Interface Options:
     
  ### Web UI: Server-side rendered Django templates styled with responsive Tailwind CSS.
  ### REST API: Fully decoupled endpoints powered by DRF with JWT Authentication (`djangorestframework-simplejwt`).
